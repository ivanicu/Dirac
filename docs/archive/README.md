# Documentation archive

Files under `YYYY-MM-DD/` are dated evidence, audits, benchmarks or superseded plans.
They are retained so design decisions and measurements remain inspectable, but they are
not maintained as current operational guidance.

Use the root [`README.md`](../../README.md), [`STATUS.md`](../../STATUS.md),
[`ARCHITECTURE.md`](../../ARCHITECTURE.md), and [`docs/README.md`](../README.md) for the
current repository.
